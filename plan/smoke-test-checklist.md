# Tauri Desktop — Manual Smoke Test Checklist

Использовать ПОСЛЕ установки .dmg (или .msi/.exe на Windows).

## macOS (.dmg)

- [ ] DMG монтируется без ошибок
- [ ] Drag-to-Applications проходит
- [ ] Первый запуск через ПКМ → Open работает (Gatekeeper bypass)
- [ ] Открывается окно с заголовком "Telegram Assistant", размер 1200×800
- [ ] **Авторизация**: вводим номер → код → код 2FA (если есть) → попадаем на главный экран
- [ ] **Список диалогов**: загружается (видим имена/последние сообщения)
- [ ] **Открытие диалога**: клик по диалогу → открывается чат с историей
- [ ] **Отправка**: вводим текст → отправляем → видим себя в чате
- [ ] **WebSocket**: пишет другой человек → сообщение появляется БЕЗ ручного refresh
- [ ] **Уведомление**: при новом входящем сообщении появляется banner в правом верхнем углу с title=имя_чата, body=текст. Если не появляется — System Settings → Notifications → Telegram Assistant → разрешить.
- [ ] **Клик по уведомлению**: фокусит окно + переключает на нужный чат
- [ ] **Системный трей**: иконка в menu bar присутствует
- [ ] **ЛКМ по трею**: окно toggle (скрывается/показывается)
- [ ] **ПКМ по трею** (или клик с зажатым Ctrl): меню Show / Hide / Quit
- [ ] **Закрытие × окна**: окно скрывается в трей, процесс продолжает работать (видно в Activity Monitor)
- [ ] **Двойной запуск**: повторный двойной клик по .app — второе окно НЕ открывается, первое фокусится
- [ ] **Quit из трея**: процесс полностью завершается (Activity Monitor пуст)

## Windows (.exe / .msi)

Аналогично. Особенности:
- SmartScreen → More info → Run anyway при первом запуске
- Notifications: Settings → System → Notifications → Telegram Assistant → On
- Tray иконка — в правом нижнем углу (system tray), может быть скрыта под "^"
- Close × → hide to tray
- Quit из tray menu

## Edge Cases (если есть время)

- [ ] **Сеть отвалилась**: WS должен переподключаться автоматически (видно по console.log "[ws] reconnecting"). После восстановления — снова приходят real-time сообщения.
- [ ] **Долгий простой**: оставить открытым на час → WS не должен умереть (nginx proxy_read_timeout=86400s, керим 24 часа)
- [ ] **Multi-account**: переключение аккаунта — список диалогов перезагружается под нужный
- [ ] **Большое сообщение**: > 200 символов → в notification body обрезается до 200 (по дизайну хука)

## Что делать если что-то не работает

| Симптом | Где смотреть |
|---|---|
| Белый экран при запуске | DevTools (Cmd+Option+I на mac), смотри Console |
| Нет уведомлений | OS Settings → Notifications для приложения; в DevTools — console.warn от useDesktopNotifications |
| Иконка трея не появляется | Запустить из терминала, смотреть stderr: `/Applications/Telegram\ Assistant.app/Contents/MacOS/tg_assistant` |
| API не отвечает | `curl https://185-252-215-73.nip.io/healthz` — проверить бэкенд |
| WS падает | DevTools → Network → WS → закрыто? Backend жив? |
